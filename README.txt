SUIVI LOCATIF v2.0 - update (3 files)

UPDATE WITHOUT LOSING DATA (recommended)
 1. In the CURRENT app: Settings -> Backup -> "Export a backup" (keep the .json as a safety copy).
 2. Unzip this file in the Files app. You get index.html, sw.js, manifest.webmanifest.
 3. In your GitHub repository (Safari): Add file -> Upload files -> select the 3 files -> Commit changes.
    Same names = they replace the old files. Wait ~1-2 minutes for GitHub Pages.
 4. Close the app completely (swipe it away) and reopen it. If it still shows the old version,
    close and reopen once more. Settings (bottom) shows "Version 2.0". From now on the button
    "Update app (keeps your data)" does this for you.
 Your data is stored under the same web address, so it is still there after the update.

IF YOU USE A NEW ADDRESS / NEW HOSTING
 Data does not follow a new address. Use your backup: new app -> Settings -> Restore from a file.
 (Backups made by v1 restore fine in v2.)

REMINDERS
 - Data lives only on the phone: export a backup regularly (it includes attached files).
 - Write down your PIN recovery code.
