SUIVI LOCATIF v3.0 - update (3 files)

UPDATE WITHOUT LOSING DATA
 1. In the CURRENT app: Settings -> Backup -> export a backup (keep the .json as a safety copy).
 2. Unzip this file in the Files app: index.html, sw.js, manifest.webmanifest.
 3. In your GitHub repository (Safari): Add file -> Upload files -> select the 3 files -> Commit changes.
    Same names = they replace the old ones. Wait ~1-2 minutes.
 4. Close the app completely and reopen it (once or twice if the old version still shows).
    Settings (bottom of the page) shows "Version 3.0". The "Update app (keeps your data)" button does the refresh for you.
 Your data stays: it is stored under the same web address. Settings and layout carry over.

NEW ADDRESS? Data does not follow. Restore your backup (works with v1, v2 and v3 backups).

NOTES
 - Encrypted backups: keep the password, there is no recovery.
 - Arabic receipts use the phone's Arabic font.
 - Leases are generated from your template; always re-read before signing.
